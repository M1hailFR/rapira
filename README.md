# Приложение Блог на Vue

Этот репозиторий содержит веб-приложение, разработанное с использованием **Vue 3 (Composition API со `<script setup>`)**, **TypeScript** и **Vite** для эффективной разработки и сборки. Стилизация реализована с помощью **Tailwind CSS**, что обеспечивает адаптивный и современный дизайн.

## Возможности:

*   **Список постов:** Отображает список постов с расширенной фильтрацией по нескольким категориям и поиском по заголовку в реальном времени. Включает плавные анимации для элементов контента.
*   **Страница с деталями поста:** Отдельная страница для каждого поста, отображающая его изображение, метаданные (дату, время чтения, количество комментариев) и полное содержание.
*   **Адаптивный дизайн:** Приложение полностью адаптивно, обеспечивая оптимальное отображение на различных устройствах и размерах экранов.

## Начало работы

Для локального запуска этого проекта вам потребуются **Node.js** (v20.9+) и **pnpm** (v10.10.0+).

Выполните следующие шаги в терминале из корневой директории проекта (`E:\GitHub\rapira`):

1.  **Установка зависимостей:**
    ```bash
    pnpm install
    ```
    Эта команда загрузит и установит все необходимые пакеты, указанные в `package.json`.

2.  **Запуск сервера разработки:**
    После установки зависимостей выполните следующую команду для запуска локального сервера разработки:
    ```bash
    pnpm dev
    ```
    Приложение обычно будет доступно в вашем веб-браузере по адресу `http://localhost:5173/` (или другому доступному порту).
